# Portfolio Motion Prototype

A one-page visual framework built around editorial typography, abstract project
media, native scrolling, and a single continuous aperture motif.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run typecheck
npm test
npm run test:e2e
npm run build
```

The current content is intentionally structural. Identity and real project
material belong in a later content phase.
